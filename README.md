# Educational Math Quiz Game

## Project Overview
Educational Math Quiz Game is a web-based application designed to test users' math skills through an interactive quiz format. The game randomly generates simple math questions involving addition, subtraction, and multiplication. Users can answer these questions and receive immediate feedback on their performance.

## Installation
To run the Educational Math Quiz Game locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   ```
2. **Change the directory**
   ```bash
   cd educational-math-quiz-game
   ```
3. **Open the HTML file in your preferred web browser**
   Simply open `index.html` or the main HTML file in your browser to start the quiz.

## Usage
1. Start the quiz by clicking the "Start Quiz" button.
2. Answer the math questions presented to you.
3. After each question, click the "Next Question" button to proceed.
4. Once you've answered all questions, you will see your final score.
5. You can restart the quiz at any time by clicking the "Restart Quiz" button.

## Features
- Randomly generated math questions (addition, subtraction, and multiplication)
- Immediate feedback on answers (correct/incorrect)
- Score tracking throughout the quiz
- Option to restart the quiz after completion

## Dependencies
Currently, there are no dependencies specified in a package.json file since the project is built solely using HTML and vanilla JavaScript.

## Project Structure
The project consists of the following main file:
- `index.html` (or similar name corresponding to the HTML file):
  - Contains the main structure of the quiz game, including HTML markup and embedded JavaScript for functionality and styling.
  
The structure of the HTML file is as follows:
- **Head Section**: Contains the title and embedded CSS styles for the game interface.
- **Body Section**:
  - A container for the game interface.
  - Buttons to start the quiz, navigate questions, and restart.
  - Elements to display questions, answer buttons, and scoring information.
  
Emphasis has been placed on user experience and visual appeal through CSS styling.
